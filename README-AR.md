# غسيلك — نسخة مستقلة

موقع عام جاهز للنشر على أي استضافة تدعم HTML وCSS وJavaScript. لا يتطلب حسابًا أو اشتراكًا أو مفاتيح Higgsfield، ولا يعتمد على خوادمه. الصور والفيديو محفوظة داخل الموقع. الخطوط من Google Fonts، والطلب عبر واتساب.

## رفع النسخة الجاهزة
فك ضغط ملف `ghasilak-ready-to-host.zip` وارفع **محتوياته** إلى مجلد الموقع العام لدى الاستضافة. يجب أن يكون `index.html` في جذر المجلد المنشور. يتطلب رابط HTTP أو HTTPS؛ لا تختبره بالنقر على الملف محليًا.

## النشر من GitHub
اختر المستودع، ثم اضبط مجلد المشروع على `app`، أمر البناء `npm run build`، ومجلد النشر `dist`. يستخدم البناء Node.js 22. هذه استضافة ملفات ثابتة ولا تحتاج قاعدة بيانات أو خادم Node لتشغيل الموقع بعد البناء.

## التطوير والبناء
```sh
cd app
npm ci
npm run dev
npm run build
npm run preview
```
مخرجات `app/dist` تتضمن HTML جاهزًا لقراءة محركات البحث قبل تشغيل JavaScript. ولإضافة الرابط النهائي وملف sitemap، عيّن متغير البناء `SITE_URL` إلى رابط الاستضافة الجديد ثم أعد البناء. احرص أن تنتهي روابط المجلدات الفرعية بشرطة `/`.

GitHub Actions يفحص كل تحديث ويوفّر حزمة `ghasilak-ready-to-host` للتنزيل. النشر التلقائي يتطلب ربط الاستضافة بالمستودع. لا ينشر هذا المستودع إلى Higgsfield.
