# غسيلك GHASILAK
نسخة الموقع بعد تحديث نطاق الخدمة إلى سلطنة عُمان وإضافة المحافظات.
الموقع المنشور: https://ghasilak-muscat.higgsfield.app
النسخة المصدرية: 0963192

## محتويات الملف
- app/src: كود الموقع العربي والإنجليزي والتصميم.
- app/public: الشعار والصور والفيديو وأيقونات الموقع.
- app/packages: حزم القالب المحلية المطلوبة للتشغيل.
- app/bun.lock: إصدارات الاعتماديات.
- refs: لوحة التصور البصري.
- FILES-SHA256.txt: بصمات الملفات للتحقق من سلامتها.

## تشغيل الموقع على جهازك
هذه نسخة مشروع قابلة للتعديل، وليست ملف HTML يُفتح بالنقر المزدوج.
ثبّت Node.js 22 أو أحدث وBun، ثم افتح الطرفية داخل مجلد GHASILAK وشغّل:
```sh
cd app
bun install --frozen-lockfile
bun run dev
```
افتح الرابط الذي يظهر في الطرفية. يتطلب تثبيت الاعتماديات اتصالًا بالإنترنت؛ الخطوط تُحمّل من Google Fonts.

## فحص وبناء نسخة الإنتاج
```sh
bun run typecheck
bun run build
```
المشروع مبني باستخدام React وTanStack Start، ونسخة الاستضافة الحالية تستهدف Cloudflare Worker.
للنقل إلى استضافة أخرى، قد يلزم تكييف إعدادات الاستضافة والروابط الأساسية.

## أهم الملفات
- app/src/routes/index.tsx: أقسام الصفحة.
- app/src/lib/ghasilak.ts: رقم واتساب ورسالة الطلب والمحافظات والأسئلة.
- app/src/ghasilak.css: التنسيق المتجاوب.
- app/src/scroll-scrub-scenes.ts: النصوص والفيديو المتحرك بالتمرير.
- app/src/app-meta.json: عنوان الموقع ووصفه وصورة المشاركة.
